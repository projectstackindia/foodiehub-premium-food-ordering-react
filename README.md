# 🍔 FoodieHub Premium Food Ordering System 🍽️🔥

---

## 📌 About Project

FoodieHub is a modern high-end responsive food ordering web application built using React Vite and Tailwind CSS. Users can browse dishes in a premium UI search food items filter categories and manage cart items with smooth real-time interactions.

💾 Cart data is stored inside localStorage so the cart remains saved even after page refresh.

---

## 🛠 Tech Stack

- ⚛️ React Functional Components & Hooks
- ⚡ Vite
- 🎨 Tailwind CSS Glassmorphism & Neon Glow Design
- 🟨 JavaScript ES6+
- 💾 localStorage

---
